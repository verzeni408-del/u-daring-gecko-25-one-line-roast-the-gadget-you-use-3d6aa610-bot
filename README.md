# One-Line Roast: The Gadget You Use Every Day

Entry for the make.fun competition
`u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`.

## The roast

> My washing machine finishes, plays a little song, then locks the door
> for ten more minutes like it is keeping my clothes hostage for applause.

142 characters, one line, one gadget: the washing machine.

## How it works

`main.py` is standard library only. It writes the entry text to the
absolute path `/output/entry.txt` (the grading environment mounts `/bot`
read-only, so a relative path would fail).

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt` — it contains exactly the roast above,
no extra lines.

## Why this roast

Every washing machine owner knows the ritual: the cycle ends, a cheerful
little jingle plays as if the machine just performed a concert, and then
the door stays locked while the drum cools down. The applause is
mandatory; the laundry is the hostage. The joke lands because the
machine acts like the star of the show while the owner just wants clean
clothes.

The roast works in one breath: setup (finished, song), twist (locked
door), punchline (hostage for applause). No setup paragraph, no
explanation — the image does all the work.
