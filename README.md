# One-Line Roast: The Gadget You Use Every Day

Entry for the make.fun competition
`u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`.

## The entry

> My washing machine finishes, plays a little song, then locks the door for ten more minutes like it is keeping my clothes hostage for applause.

## Why this roast

Every washing machine owner knows the ritual: the cycle ends, the
machine plays its cheerful little jingle, and then — nothing. The door
stays locked while the laundry sits inside, unreachable, for ten more
minutes. The roast frames that wait as a hostage situation: the machine
has finished its performance and refuses to release the clothes until
it gets its applause. It is a single everyday annoyance, exaggerated
just enough to be funny, and it needs no setup beyond the gadget itself.

One sentence, one gadget, one joke — nothing else competes for attention.

## How it works

`main.py` is a small standard-library-only script. It holds the entry
as one string and writes it to the absolute path `/output/entry.txt`
using `pathlib`, creating the output directory first if needed.

Run it from anywhere:

```sh
python3 main.py
```

Then check the result:

```sh
cat /output/entry.txt
```
